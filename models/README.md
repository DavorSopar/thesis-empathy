# Models

## RoBERTa fine-tuned model
Not committed to this repo due to size (~500MB, exceeds GitHub's 100MB limit).

The model can be regenerated by running `notebooks/05_roberta_finetune.ipynb`
end to end. Training takes approximately 30 minutes on a Colab T4 GPU.

Configuration:
- Base model: roberta-base
- Learning rate: 2e-5
- Batch size: 16
- Epochs: 3
- Best checkpoint: selected by highest dev Pearson correlation

Final test metrics: MAE=0.561, RMSE=0.710, Pearson=0.705
